# 10 증례 대시보드

실행 호스트는 PC1 `MEDIIOT-SKLEE`다. 2026-10-27 격리 후보에서 확인한 내용만 적는다. 환자 원본과 DeeVo는 열지 않았다.

## 문제

연구 사이트 안의 초안과 확정 측정이 한 화면에 섞이면, 아직 확정되지 않은 값을 확정 분포처럼 읽을 수 있다.

## 구현 결정

대시보드는 읽기만 한다. TBUT, OSDI, Schirmer는 FINAL과 DRAFT를 따로 집계한다. 선택 대상자의 출처에는 관찰의 source, unit, record_status가 있다. 품질과 질의는 상태별 건수다. 가져오기 대조는 배치 수, 매핑 버전, 스테이징 상태, 불일치 건수다. 원본 행은 저장하지 않는다. OSDI는 다시 계산하지 않는다.

안전 기본값은 `enable_r1` false, `protocol_advisory_id` 비어 있음, `window_check` false다. 자동 수정, 확정, 잠금은 하지 않고 배정 값은 조회하지 않는다. 라우트는 기존 `clinical_observation_read`를 쓰고, 사이트 구성원이 아니면 거절한다.

## 실험과 결과

SQLite 임상 묶음은 83 passed, 4 skipped, 종료 코드 0이었다. 정책 테스트는 8 passed다. 일회용 PostgreSQL 15는 `medi010`까지 올라갔고, 관찰·질의·잠금·가져오기를 두 순서로 각각 4 passed였다. aiosqlite 워커는 남지 않았다.

브라우저에서 합성 대상자 SYN-01의 연구 개요, 방문 V1–V3, FINAL/DRAFT 차트, 출처, 품질 1건, 질의 1건, 가져오기 배치 1건을 확인했다. 토큰이 없으면 401이고, 사이트 구성원이 아니면 403이다.

권한 실패, 연구나 사이트 변경, 대상자 변경, 불러오기 실패가 생기면 방문, 차트, 출처, 품질, 질의, 가져오기 표시를 바로 지운다. 이전 요청의 응답이 나중에 도착해도 요청 세대가 다르면 다시 그리지 않는다. 2026-10-27 브라우저에서 토큰을 바꾸는 즉시 합성 대상자 표시가 사라졌고, 이어서 403이 와도 패널은 비어 있었다.

## 아직 없는 것

질의 사건 목록과 감사 추적 상세는 없다. 권한 없는 토큰으로 다시 불러오면 화면은 거절 문구를 띄우지만, 직전에 표시한 패널을 지우지는 않는다.

## 다시 쓸 수 있는 설명

확정 값과 초안 값을 같은 상자에 넣지 않는다. 숫자는 저장된 관찰에서만 읽고, 계획서 규칙으로 다시 만들지 않는다.
